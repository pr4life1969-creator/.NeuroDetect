
# NeuroDetect

This repository contains the NeuroDetect Android app.

## Build Instructions
1. Upload this project to a new GitHub repository named "NeuroDetect".
2. Go to the "Actions" tab and run the "Build Android APK" workflow.
3. After the workflow completes, download the artifact ZIP which contains the app-debug.apk.
4. Install app-debug.apk on your Android device.
